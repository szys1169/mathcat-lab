# 检索、筛选与论文归档

## 检索层次

依次搜索：问题原名和别名、提出者/原始来源、标准对象与定理名、引用链、特殊情形、推广、反例、方法性论文、综述、最近成果。保存每条查询、来源、时间、结果数量和失败原因。

优先使用原始论文、作者公开预印本、出版社元数据、数学数据库和权威机构页面。普通搜索结果只作为定位线索，重要结论必须回到原文或可靠元数据核验。

## 三级筛选

依次进行标题、摘要、全文或关键章节筛选。每篇记录 `included/excluded/pending`、理由、相关性、证据等级和所属类别。核心论文不能只凭标题纳入。

## 去重与下载

优先标识：DOI → arXiv ID → 规范化标题与作者/年份。期刊版与预印本保留版本关系，但在统计中视为同一工作。

只下载开放获取、作者公开或用户有权访问的文件。不可下载时在 `待获取/README.md` 登记标题、DOI/URL、访问状态和当前可用证据；不得绕过付费墙或访问控制。

文件名建议：`年份-第一作者-标题缩写-稳定标识.pdf`。保存 SHA-256、下载 URL、获取时间和版本。损坏、HTML 冒充 PDF、OCR 失败或正文不可提取必须显式标记。
