# 记号与公式可读性审计

维护一份符号台账，让记号支撑理解而不是掩盖错误。本审计只动记号与展示形式，不改数学含义。

## 符号台账

输出：

- Symbol ledger：符号、首次出现与首次定义位置、对象类型、底环/环境对象、作用域、维数、复用位置。
- Drift report：重载符号、未定义符号、改名对象、指标变化、约定冲突。
- Patch suggestions：具体 TeX/文字修改 + 保义说明。

推荐表格：

| Symbol/object | First occurrence | First definition | Type | Base/ambient object | Source notation | Status/action |
|---|---|---|---|---|---|---|

对映射另记定义域、陪域与作用公式；对相对对象另记基域、底环或所在范畴。

## 扫描范围

- 定义、定理陈述、算法、公式、证明、图表中的符号。
- 记录首用位置与期望数学角色；把后续用法与台账比对。
- 标记定义域、维数、指标、记号冲突。
- 核心对象和非标准符号必须在首次实质使用前定义或精确引用；标题、摘要中的前瞻性提及不替代正文定义。

## 首次使用与记号决策

- 元组、分量、集合、矩阵、环、理想和映射在语义不同且可能混淆时，使用可区分的字体或名称；例如元组 `\mathbf{x}` 不与分量 `x` 共用同一写法。
- 参数化族先定义每个参数点对应的对象，再陈述族上的不变量、同构或等式。
- 多篇来源使用冲突记号时，选择一种主记号并全局使用；对照关系写入 `writer/style_decisions.md`，不要在正文保留修订过渡文字。
- 引入标准对象时，根据目标读者选择“正式定义”或“精确引用”；不可只依赖缩写或默认常识。
- 理想、环、矩阵、映射和编号关系的文字指称必须与 `\label`、来源定理或声明台账交叉核对，不手工依赖易漂移的编号。

## 关系与公式的语义角色

作者引入的恒等式、关系或生成元列表必须标记其角色：

- `definition`：定义对象或记号；
- `compatibility`：说明多个定义/去分母表达相容；
- `consequence`：由前序关系推出；
- `redundant`：为方便使用而保留、但不含独立信息；
- `independent-claim`：需要单独证明或来源支持。

若关系是等价改写或冗余关系，正文应简短说明，不把它包装成新的独立结论。

## 公式环境选择

| 角色 | 环境 |
|---|---|
| 单一对象 | `equation` |
| 对齐推导 | `align` |
| 单编号多行公式 | `split` |
| 超长表达式 | `multline` |
| 分段定义 | `cases` |

避免 `eqnarray` 与裸 `$$`；保留标签、编号意图、标点与数学含义。

## 长公式与连乘的排版纪律（语料实践）

长恒等式/长分子在默认 `\displaystyle` 下容易超出文本区（Overfull hbox）。处理顺序如下，禁止直接跳到最后一步：

1. **`\textstyle` 分式（首选）**：长分式用 `{\textstyle\frac{...}{...}}` 保持单行显示，数学内容一字不变，宽度显著缩小。这是长分式的最佳方案，不产生任何换行。
   ```tex
   &={\textstyle\frac{(q_0-q)(qq_0+q+q_0)(1-qq_0)(qq_0+q_0+1)(q+q_0+1)(qq_0+q+1)}
   {4q_0^6a_1^6S^3}},\\
   ```
2. **等价重排（次选）**：仅当 `\textstyle` 仍超宽时，把尾部因子移到分式外并保留全部因子（纯乘法交换，数学等价）：
   `\frac{AB}{C}\,D` 代替 `\frac{ABD}{C}`。不得丢因子、不得改表达式。
3. **按运算符断行（最后手段）**：换行点选在 `=`、`+`、`\times`、逗号等运算符处，续行用 `\qquad` 缩进；绝不在因子内部或分子内部断开（`\begin{gathered}` 式分子拆行视觉突兀，禁止用于连乘分子）。

禁止事项：

- 禁止 `\resizebox` / `\scalebox` / `\adjustbox` 缩放公式（字号不一致、破坏可读性）。
- 禁止在数学模式中裸用 `\small`（无效并产生 Font Warning）。
- 禁止 `\begin{gathered}`/`\substack` 把连乘分子人为拆成多行。
- 禁止用 `\!` 密集压缩空格来"硬塞"公式。

源码行宽：display 公式源码按运算符断行，单行尽量 ≤ 100 字符，便于审阅与 diff。

## 规则

- 不全局改名而不检查证明依赖。
- 影响指标、维数、对象同一性的变量对齐是语义问题，不是装饰问题。
- 保留领域惯例符号（`n`, `d`, `x`, `X`, `A`, `\epsilon`, `\delta`），除非草稿本身使用不一致。
- prose 与公式冲突时，标记公式，不悄悄改。
- 首次定义审计不仅检查“是否出现定义句”，还检查对象类型、底环、作用方向和适用范围是否足够。
- 证明关键推导中，可读性优先于"聪明"压缩。
- 交付前必须消除 `Overfull`；逐项审阅 `Underfull` 是否影响版面，不缩小字体掩盖问题。
