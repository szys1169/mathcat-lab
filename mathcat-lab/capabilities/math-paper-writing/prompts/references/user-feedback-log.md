## 2026-08-21 · Markov 箭图论文修订（来源：用户对《带一般系数的 Markov 箭图的上丛代数有限生成》的六条意见）

来源文件（修订对象）：`writer/article_candidate_zh.tex` 与 `writer/article_candidate.tex`
（2026-08-21 候选版，含边界刻画；原编号：定义 2.1、命题 2.2、命题 2.3、引理 2.4）。

### 反馈条目

1. **字体纪律（种子元组 vs 簇变量）**：`(x,B)` 中的 `x` 表示种子/簇元组，字体必须与单个簇变量
   `x` 区分。规范做法：簇元组用粗体 `\mathbf{x}`（本文新增 `\newcommand{\bx}{\mathbf{x}}`），
   簇变量保持斜体；`\U_x`、`D_x` 等下标中的 `x` 也应改为 `\U_{\bx}`、`D_{\bx}`。
   → skill 建议：notation-formula-audit / latex-conventions 增加"元组与分量字体必须不同"的硬检查项。

2. **第二章缺少基本对象的严格定义**：上簇代数 `\U`、上界 `\U_{\bx}`、下界 `\mathcal{L}`、
   下深理想 `D_{\bx}` 在正文使用多年后才被定义，且记号不统一（BFZ 与 MM 用 `L_x`/`\mathcal{D}_x`）。
   → 修订：第二章开头新增"记号：上簇代数、上界、下界、下深理想"小节，给出逐条严格定义
   （含包含链 `\mathcal{L}\subseteq\mathcal{A}\subseteq\U\subseteq\U_{\bx}` 与 totally coprime 时
   `\U=\U_{\bx}` 的引用），并附"记号说明"统一术语。
   → skill 建议：论文写作先列"记号与基本定义"节，核心对象必须在首次使用前定义；同时给出与文献
   记号（BFZ / MM）的对照表。

3. **"6 个交叉恒等式"含义不明**：命题证明中"六个交叉恒等式 `y(xm_i)=x(ym_i)`、`z(xm_i)=x(zm_i)`"
   没有解释意义。实际含义：它们断言 `m_i` 的三种去分母公式（除以 x/y/z）相容；且给定
   `(xm_i)` 关系后，每条分别等价于 `(ym_i)`/`(zm_i)` 关系，**不含新的信息**。
   → 修订：保留并解释其含义，明确"不是独立新恒等式、等价于已列关系"，不再单独重复列出。
   → skill 建议：作者自创的"恒等式/关系"必须注明其语义角色（定义、相容性、还是独立新关系）；
   若冗余则删去或注明。

4. **引理中记号 `(b_1...b_r)^\infty`、`B^\infty`、`A_B` 未先定义，且证明过于口语化**：
   → 修订：引理前新增"记号与准备"段，严格定义饱和理想
   `(J:b^\infty)=\bigcup_{n\ge1}(J:b^n)`、`A_B:=S^{-1}A`（`S=\{B^n\}`）；
   证明重写为规范数学证明（`\ker\psi`、局部化中 `J` 生成的主理想、`(A[T]/J)_B\cong A_B`、
   核等于 `(J:B^\infty)`），以公式推导为主、文字为辅。
   → skill 建议：涉及局部化/饱和/冒理想的引理，先给记号再给证明；证明以推导链为主，
   不写"通篇文字介绍"式的证明。

5. **第 4.1 节 `S(\alpha)`、`\U(\alpha)` 无定义**：参数化对象必须先定义再使用。
   → 修订：4.1 开头给出 `\alpha\in(K^\times)^6` 与 `S(\alpha)`、`\U(\alpha)`、
   `\mathcal{L}(\alpha)`、`\U_{\bx}(\alpha)`、`D_{\bx}(\alpha)` 的严格定义。
   → skill 建议：引入"族/参数化"记号时，先定义"对每个参数元组的对象"再写不变量等式。

6. **第 4.2 节 `r_1,r_2,r_3`、`U_1`、`M_1`、`J_{10}` 未定义**（且 `J_{10}` 被错误地
   引用为"定理 1.1 的十条关系"，实际出自命题 2.3）：
   → 修订：新增"定义 4.1"严格定义表示环 `R=\Q[r_1,r_2,r_3,X,Y,Z,U_1,U_2,U_3,M_1,M_2,M_3]`、
   九个未定元的对应关系、`J_0`（六个清分母定义关系）、`I=(J_0:(XYZ)^\infty)=\ker\varphi`、
   `J_{10}`（命题 2.3 的十条关系清分母后）、特化 `I(p)`/`J_{10}(p)`；修正所有错误引用
   （"定理 1.1 的十条关系"→"命题 2.3 的十条关系"）。
   → skill 建议：理想/环/矩阵等对象在首次使用时必须有定义或显式引用；交叉检查"第几条关系"
   的出处是否与内容一致（claim-evidence-ledger / notation audit）。

## 2026-08-22 · 第二轮反馈（同一论文）

### 反馈条目

1. **记号统一为 Matherne–Muller**：`L_x`、`U_x`、`D_x` 全部采用 MM 记号，即
   下界 `L_{\bx}`、上界 `\U_{\bx}`、下深理想 `\mathcal{D}_{\bx}`；上一轮加的
   "记号说明（BFZ/MM 对照）"注记已删除。
   → skill 建议：多文献术语冲突时直接选定一种（优先规范文献）并全局替换，
   不保留"对照说明"式的过渡文字。

2. **饱和理想、局部化等概念改为正式 Definition**：不要用 prose 段落介绍，
   直接 `\begin{definition}` 严格定义（含构造与运算、等价条件）；论文中不得出现
   "按你的要求""需要说明其含义"这类过程性/元叙述文字。
   → skill 建议：定义一律进 definition 环境，正文只保留必要引导句；自查
   "revision 过程痕迹"（如"需要说明""所谓""按用户"）不得出现在稿件里。

3. **4.3 节补 Spec 与正则的严格定义**：读者需要知道 `\operatorname{Spec}A`（素谱 +

   → skill 建议：正文首次使用标准对象（Spec、正则、S_2 等）前给出定义或显式引用，
   尤其是几何/交换代数术语；可在审阅清单增加"未定义即使用"扫描项。
