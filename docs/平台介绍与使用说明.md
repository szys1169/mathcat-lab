# MathCat Lab 平台介绍与使用说明

## 1. 平台是做什么的

MathCat Lab 是一个数学科研工作台，帮助你探索数学问题、调研文献、审核成果，并将已有材料整理成论文或汇报。你提出问题，猫猫们协作研究；你也可以随时查看进展、回答问题和提出建议。

本科研平台主要是用来帮助不太会使用codex等ai工具，没有成熟ai工作流的数学专业的老师同学使用的，如果你非常熟悉ai，有自己的工作流，那不太建议使用我们的平台了。

目前所有功能中，我们主要做的是ai论文写作和研究。论文写作的功能目前在排版和格式上是还不错的，但具体的文章名字，语言，证明细节，还有论文材料的组织顺序，最好还是明确的和ai说明/之后自己多审查。

研究功能的能力应该是一般，会比北大的rethlas差一点，我们的主要优势在于人机协作，而且我们的使用门槛比较低。

目前平台还只是一个demo，主要是用来作者为了应付一下最近的一个比赛，做的非常匆忙（10天）。如果后续调研发现大家真的有这个需求的话，我们会不断持续更新的。

目前平台是调用的是codex的cli，花费的也是本地codex的额度，后续我们应该也会接入deepseek harness的框架。

## 2. 如何使用

### （1）建立桌面快捷方式

配置好平台后，和 Codex 说：

> 帮我创建mathcat的桌面快捷方式

创建完成后，双击桌面图标即可启动并打开平台。

### （2）准备工作区和材料

新建或选择一个工作区，再新建对话。把题目、参考论文和已有成果放进工作区，并在消息中写明需要读取的文件名。选择工作区不会自动导入其中所有材料。

### （3）写清问题并开始研究

选择“研究喵”和 **MathCat**，输入完整题面，写清假设、目标和其他要求。例如：

> 请研究以下问题：……。（先检查特殊情形，再尝试证明或寻找反例；无法完成时，请整理已有进展与剩余问题。）

发送后，设置研究时长、伙伴猫上限，以及自动安排分工或由你批准分工。开始后，先核对白板上的数学问题是否准确。

## 3. 猫猫实验室如何协作

**领研猫**负责整体研究与分工，**伙伴猫**探索子问题，**审核猫**检查提交的候选成果。顾问猫、记忆猫和展示猫辅助整理路线、经验与进展。

能够独立开展的任务可以并行，有依赖的任务需要等待前置结果。实验室主要展示领研猫与伙伴猫；审核情况可在成果及审核记录中查看。模型审核不等于形式化证明，重要结论仍需你核对。

## 4. 如何使用白板

- **数学问题**：核对当前题面，需要更正时使用修改入口。
- **实验室**：查看猫猫正在做什么，展开任务或点击“查看详情”阅读文本回复，也可以向指定猫提出建议。
- **证明树**：查看成果、证明和依赖关系，结合审核意见判断哪些结论可以使用。
- **猫猫提问箱**：有问题时显示“猫猫们需要你的建议”，打开并回答；没有时显示“猫猫们暂时没有疑问”。
- **人工审核**：选择人工批准分工时，在这里检查并批准或退回安排。
- **成果与记录**：阅读中英文阶段报告，按需整理成论文；查看开放疑点、失败路线和历史记录。

右侧可选择旁观讨论、提出建议或修改问题。**旁观讨论用于交流理解，不直接改变研究安排**；希望调整研究时，请使用建议或修改入口。

需要中途离开时可以暂停研究。关闭浏览器不会停止后台研究。
