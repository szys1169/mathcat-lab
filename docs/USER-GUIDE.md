# MathCat Lab 2.5.1 使用说明

> 当前 2.5.3 的简明介绍请阅读 [平台介绍与使用说明](平台介绍与使用说明.md) 或 [PDF 版](MathCat-Lab-User-Guide.pdf)。本文保留为旧版操作参考。

## 启动与输入

按根目录 README 准备环境，运行 `scripts/start-version.ps1`，访问 http://127.0.0.1:4335/。当前是本地实例，每位试用者应使用独立实例，或在有人协助时轮流操作同一台测试机。

每个主题使用独立工作区与对话。研究建议直接粘贴完整题目，写清对象、假设、量词和所求结论，另列时间或方法要求。普通能力读取材料时，请将文件放在所选工作区并在消息中写明文件名；选择一个目录并不代表全部文件都会自动进入证据包。

短提示示例：

- 文献调研：“帮我调研 problem.md 中问题的相关文献。”
- 论文写作：“根据 results.md 中的现有成果帮我生成论文。”
- 相关工作：“根据现有材料帮我写相关工作。”
- 论文修改：“帮我检查并修改 paper.tex。”
- 汇报：“根据现有材料帮我生成汇报 PPT。”

论文写作需要已有的详细成果；若材料尚不充分，应保留缺口，不将未证明的候选包装为已完成定理。多篇论文并存时，应明确选择要处理的主稿。

## 研究模式与白板

每次启动研究或新一轮研究时选择自动安排分工或每轮人工批准，并设置本轮时长、伙伴猫上限和完成后的成果整理选项。这不是左下角的全局开关。

白板顶部默认展示精确数学问题，展开说明可看其他要求。先核对整理后的题面，必要时修改。角色区显示当前工作和公开执行记录；证明树卡片可展开为大页面，用于搜索成果、查看精确陈述及前后依赖。

普通建议在领研猫的安排阶段处理；禁止路线属于立即生效的控制。普通伙伴改派在自然交接处实施。人工模式下，到待处理事项中检查并批准或退回本轮分工；没有批准前组织动作不会派发。

研究者提交的是候选。请结合审查结果与依赖状态阅读成果，不把摘要、模型审查或页面中的“完成”简单等同于形式化证明正确。

## 暂停、保存与成果

“暂停全部研究”只作用于当前项目。显示正在暂停时，仍在等待执行退出确认；暂停不会延长本轮截止时间。重新打开页面不会自行启动或恢复研究。

统一成果入口列出阶段报告或中英文交付，并显示需要处理的失败步骤。已经生成的部分可以保留，按入口局部重试。论文修改若涉及数学假设或证明调整，可能停在需要人工确认的状态，这不等于程序崩溃。

回复中的本地文件链接在所属工作区内打开，版本目录可以继续浏览子目录。PDF、TeX 和源文件包的可用性取决于任务实际完成情况；PPT 默认采用图片式页面，修改内容应编辑 LaTeX 后重新导出。

左下角显示模型及每周额度。模型设置在下一次调用生效，不会中断当前调用。额度读取失败时，查看标记的更新时间，不将未知额度当成零。

需要协助时保留对话和错误信息，记录操作步骤、预期结果和实际结果。不要删除数据库或未知调用记录来“解除”问题。关闭平台请使用本实例的停止脚本；备份时在停止后一起保存 `workspaces/`、`runtime/` 和 `math-lab-platfrom/runtime-data/`。
