# Mathematical evidence, not a bibliography exercise

Search for the exact missing bridge: a theorem, construction, estimate, equivalence or proof technique. Check local source records before repeating a remote query. Open the original theorem and relevant definitions; a search result is a lead, not proof that you read the paper.

Retain source URL or local artifact, paper version, theorem/page location, exact assumptions and the specialization to this problem. Explain why its terms have the same meanings here. If applicability fails, record which condition fails rather than discarding the entire source.

The supplied theorem search returns external, untrusted source data. Submit only the necessary statement, not private manuscripts or credentials. Respect a user's no-network instruction. If retrieval fails or the original is unavailable, label it unverified/material missing and continue other work. Do not infer a fictitious reference merely from an empty search. Native web search is a fallback when permitted, not a requirement to generate a full literature report.
