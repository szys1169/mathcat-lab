# 引言写作模式与 Checklist

## 四种开头模式（按素材自动选型）

| 模式 | 适用素材 | 示例结构 |
|---|---|---|
| 问题定义式 | 先有研究对象定义 | 定义对象 → 定义问题 → 历史影响 → 本文 |
| 历史推进式 | 已知结果链条完整 | 已知结果逐一列出 → 本文突破 → 主定理 |
| 模型/工具式 | 本文提出新对象/技术 | 提出新对象 → 与已有对比 → 应用/主定理 |
| 对象+图例式 | 几何/概率对象直观 | 图/例子 → 核心定义 → 主定理 |

## 引言 Checklist（输出前逐项打勾）

- [ ] 第一段给出研究对象与问题（或一张图/一个例子）
- [ ] 2–6 句内出现动机或问题意义
- [ ] 已知结果按时间线归因引用（"was proved by X [n]"）
- [ ] 主定理在引言前 1–2 页内完整陈述（长论文可给定理清单 + 思路）
- [ ] 一段证明思路/方法说明
- [ ] （可选）"The paper is organized as follows" 结构段

## 高频句式

```
The following is our main result.
Our first main theorem is the following.
Building on the work of [n], we prove ...
We introduce a new ... which can be analyzed rigorously to ...
The proof of Theorem 1.1 is completed in Section 4.
```
