# 记号与公式可读性审计

维护一份符号台账，让记号支撑理解而不是掩盖错误。本审计只动记号与展示形式，不改数学含义。

## 符号台账

输出：

- Symbol ledger：符号、首次定义位置、类型/定义域、作用域、维数、复用位置。
- Drift report：重载符号、未定义符号、改名对象、指标变化、约定冲突。
- Patch suggestions：具体 TeX/文字修改 + 保义说明。

## 扫描范围

- 定义、定理陈述、算法、公式、证明、图表中的符号。
- 记录首用位置与期望数学角色；把后续用法与台账比对。
- 标记定义域、维数、指标、记号冲突。

## 公式环境选择

| 角色 | 环境 |
|---|---|
| 单一对象 | `equation` |
| 对齐推导 | `align` |
| 单编号多行公式 | `split` |
| 超长表达式 | `multline` |
| 分段定义 | `cases` |

避免 `eqnarray` 与裸 `$$`；保留标签、编号意图、标点与数学含义。

## 长公式与连乘的排版纪律（语料实践）

长恒等式/长分子在默认 `\displaystyle` 下容易超出文本区（Overfull hbox）。处理顺序如下，禁止直接跳到最后一步：

1. **`\textstyle` 分式（首选）**：长分式用 `{\textstyle\frac{...}{...}}` 保持单行显示，数学内容一字不变，宽度显著缩小。这是长分式的最佳方案，不产生任何换行。
   ```tex
   &={\textstyle\frac{(q_0-q)(qq_0+q+q_0)(1-qq_0)(qq_0+q_0+1)(q+q_0+1)(qq_0+q+1)}
   {4q_0^6a_1^6S^3}},\\
   ```
2. **等价重排（次选）**：仅当 `\textstyle` 仍超宽时，把尾部因子移到分式外并保留全部因子（纯乘法交换，数学等价）：
   `\frac{AB}{C}\,D` 代替 `\frac{ABD}{C}`。不得丢因子、不得改表达式。
3. **按运算符断行（最后手段）**：换行点选在 `=`、`+`、`\times`、逗号等运算符处，续行用 `\qquad` 缩进；绝不在因子内部或分子内部断开（`\begin{gathered}` 式分子拆行视觉突兀，禁止用于连乘分子）。

禁止事项：

- 禁止 `\resizebox` / `\scalebox` / `\adjustbox` 缩放公式（字号不一致、破坏可读性）。
- 禁止在数学模式中裸用 `\small`（无效并产生 Font Warning）。
- 禁止 `\begin{gathered}`/`\substack` 把连乘分子人为拆成多行。
- 禁止用 `\!` 密集压缩空格来"硬塞"公式。

源码行宽：display 公式源码按运算符断行，单行尽量 ≤ 100 字符，便于审阅与 diff。

## 规则

- 不全局改名而不检查证明依赖。
- 影响指标、维数、对象同一性的变量对齐是语义问题，不是装饰问题。
- 保留领域惯例符号（`n`, `d`, `x`, `X`, `A`, `\epsilon`, `\delta`），除非草稿本身使用不一致。
- prose 与公式冲突时，标记公式，不悄悄改。
- 证明关键推导中，可读性优先于"聪明"压缩。
- 交付前编译日志必须无 `Overfull`/`Underfull` 警告；有则按上述纪律重排，不缩小字体掩盖。
