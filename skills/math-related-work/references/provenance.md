# 归因纪律与来源标记解读

## 来源标记（findings / source packet）

每条已知结果带来源标记：

| 标记 | 写作处理 |
|---|---|
| `proved (primary theorems)` | 作为已确立事实陈述，首次出现处引用 |
| `proved in source` | 同上（结果在源文献中被证明） |
| `attributed` | 写成"作者声称/该文提出"，引用，不背书其正确性 |
| `attributed (open problem)` | 明确标注为开放问题，绝不写成已解决 |
| `secondary mention` | 只作线索，不直接进综述；需经 source-theorem 审计 |

## 来源信任级别

- `cite-as-existing`（已有结果，来源已核实）→ 渲染为归因定理：`\begin{theorem}[{\citet{key}}]` 或 "by a theorem of X [n]"。
- `borrowed`（借用结果，义务已结清）→ 可作载荷引用。
- `original`（本文原创）→ 作为本文贡献呈现，不归因。

## 文献验证清单（综述引用前必做）

- 确认书目事实：标题、作者、年份、期刊/会议、DOI、arXiv ID。
- 区分 preprint 与同行评审版本；引用最权威的当前版本，版本不一致时说明。
- 核对引用确实支撑所挂论断——只凭标题像是不够的。
- 综述按主题/方法分组（见 patterns.md），不用无结构的罗列。
- 区分"来源陈述了什么"与"你从中推断了什么"。
- 快速变化的话题显式标注时效。

## 来源层级

- 首选一手来源：原始论文、出版社页面、官方文档、项目主页。
- 新闻、博客、二手综述仅作背景，除非用户明确要求。
- 重要论断（日期、量化结果、优先权）尽量交叉核对多个来源。

## 硬性归因规则

1. 载荷引用只能来自引用白名单（来源信任记录）；综述性提及可补充，但必须真实可解析。
2. 已有结果绝不写成原创；原创结果绝不冒充已有。
3. 每条被引结果要写准适用范围：假设、维数、系数域、收敛条件等，宁少勿泛。
4. 引用位置：首次载荷使用处引用一次，之后自然叙述，不重复堆叠。
5. 不写内部路径、不写 agent 历史；参考文献以 `\citet`/`\citep` 形式出现。
